# 📊 Power BI AI Journey

> Mon parcours complet pour maîtriser Power BI, DAX, et l'Intelligence Artificielle appliquée à la Business Intelligence

---

## 🎯 Objectif du Projet

Devenir un expert en :
- **Power BI** (Desktop, Service, Embedding)
- **DAX** (Fondamental à Avancé)
- **Power Query (M Language)**
- **Modélisation de données**
- **Intelligence Artificielle** appliquée à la BI
